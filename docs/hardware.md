# ハードウェア構成 - esp32-rc-car

スマホ（Android Chrome）からBLEで操作する、2WD戦車式リモコンカーのハードウェア構成をまとめる。
ピン番号やしきい値は `firmware/src/config.h` の値と一致させている。変更したときは両方を直す。

## 1. 全体構成

```
[Android スマホ]  PWA (Web Bluetooth)
      │  BLE
      ▼
[ESP32-C3] ──PWM/方向/STBY──▶ [TB6612FNG] ──▶ 左モーター（A側）
      ▲ 5V          ▲ 3.3V          ▲ VM   └─▶ 右モーター（B側）
      │             │               │
      │        (VCCへ供給)           │
 [降圧DC-DC 5V] ◀────────────── [電源SW] ◀── [18650 ×2 直列（2S 7.4V・保護回路付き）]
                                    │
                                    └─ 100kΩ ─┬─ 33kΩ ─ GND
                                              └─▶ GPIO3（電池電圧の測定）
```

- 走り方は**戦車式**。左右のモーターの回転差で曲がる（ステアリング機構なし）。
- 電池は1系統で、モーター（VM）には電池の電圧を直接、ESP32にはDC-DCで降圧した5Vを供給する。
- モーターの電圧はファームでPWMの上限を絞って定格内に収める（「4. 電源系」を参照）。

### 3.2 TB6612FNG モジュール

| 端子 | 接続先 | 備考 |
|---|---|---|
| VM | 電池＋（電源スイッチの後） | 470µFをこの端子のすぐ近くでGNDとの間に入れる |
| VCC | ESP32の3.3V | ロジック電源 |
| GND | 共通GND | モジュールのGND端子はすべてつなぐ |
| AIN1 / AIN2 / PWMA | GPIO4 / GPIO5 / GPIO6 | 左モーター |
| BIN1 / BIN2 / PWMB | GPIO0 / GPIO1 / GPIO7 | 右モーター |
| STBY | GPIO10 | |
| AO1 / AO2 | 左モーター | 前進で逆に回る場合は `LEFT_MOTOR_INVERT` を true にする（配線の入れ替えでも可） |
| BO1 / BO2 | 右モーター | 同上、`RIGHT_MOTOR_INVERT` |

モーターの回転と入力の関係（TB6612FNGの真理値表）:

| IN1 | IN2 | PWM | 動作 |
|---|---|---|---|
| H | L | デューティ比 | 正転（前進） |
| L | H | デューティ比 | 逆転（後退） |
| H | H | — | ショートブレーキ（停止・非常停止で使用） |
| — | — | STBY=L | 出力を切り離す（未接続・通信途絶時） |

### 3.3 電源・その他

| 配線 | 接続 |
|---|---|
| 電池＋ | 電源スイッチ → TB6612FNG VM、DC-DC入力＋、分圧抵抗100kΩ |
| DC-DC出力＋（5V） | ESP32の5Vピン |
| 電池電圧の分圧 | 電源スイッチの後の電池＋ ─ 100kΩ ─ GPIO3 ─ 33kΩ ─ GND |
| GND | 電池−、DC-DC入出力−、TB6612FNG GND、ESP32 GND を共通にする |

分圧抵抗を電源スイッチの後につなぐのは、スイッチOFFのときに電池が放電しないようにするため。

## 4. 電源系

### 4.1 電圧

| 箇所 | 電圧 | 備考 |
|---|---|---|
| 電池（2S） | 6.4〜8.4V | 満充電8.4V、公称7.4V。6.4V未満で走行を止める |
| モーター（VM） | 電池電圧そのまま | PWMの上限を70%にしており、実効 最大約5.9V（8.4V × 70%） |
| ESP32 5Vピン | 5.0V | DC-DC出力。基板上のレギュレーターで3.3Vにする |
| TB6612FNG VCC | 3.3V | ESP32の3.3Vピンから |
| GPIO3（ADC） | 約1.59〜2.08V | 電池電圧 × 33 / (100 + 33) |

### 4.2 電流の目安

| 負荷 | 電流の目安 | 備考 |
|---|---|---|
| TTモーター（走行中） | 約0.2〜0.5A ×2 | 負荷や個体で変わる |
| TTモーター（起動・停止寸前） | 約1A以上 ×2 | 発進時・壁に当たったとき。加速制限で突入電流を抑えている |
| ESP32-C3（BLE通信中） | 約0.1A | |
| 合計（ピーク） | 約2.5A | 電池・電源スイッチ・保護回路は3A以上に耐えるものを選ぶ |

### 4.3 電池電圧の測定

- 分圧比は 33 / (100 + 33) ≒ 0.248。8.4Vが約2.08Vになり、ESP32-C3のADCで正しく測れる範囲（約2.5Vまで）に収まる。
- 分圧抵抗に流れる電流は約63µA（8.4V ÷ 133kΩ）。
- ファームでは移動平均でならしたうえで、6.4Vを3秒続けて下回ったら走行を止める。電源を入れ直すまで解除しない。
- 測定値が3.0V未満のときは「電池なし（USB給電）」とみなし、低電圧の判定をしない。

## 5. ノイズ・リセット対策

モーターのノイズや起動時の電圧低下でESP32がリセット（ブラウンアウト）しやすいため、次の対策をとる。

| 対策 | 内容 |
|---|---|
| 電解コンデンサ | 470µFをTB6612FNGのVM–GND間、端子のすぐ近くに入れる |
| セラミックコンデンサ | 0.1µFを各モーターの端子間に直接はんだ付けする |
| GNDの取り回し | モーター側の大電流がESP32のGNDを通らないよう、電池−の近くの1点でまとめる |
| 電源の分離 | ESP32はDC-DC経由でモーターと直接つながらないようにする |
| 加速制限（ファーム） | 出力を毎秒400%までしか変えず、急な電流変化を避ける |
| PWM周波数（ファーム） | 20kHzにして、モーターの可聴音を消す |

## 6. 組み立て・確認の手順

1. **DC-DCの出力調整**: ESP32をつなぐ前に、電池を入れて出力を5.0Vに合わせる。
2. **ESP32単体**: USBで書き込み、スマホから接続できることを確認する。分圧抵抗をまだ付けていない場合は、GPIO3をGNDにつないでおく（ピンが浮いていると低電圧と誤判定して走らないことがある）。
3. **モーター配線**: TB6612FNGとモーターをつなぎ、車輪を浮かせた状態でシリアルモニタから `D 50 0` を送る。両輪が前進方向に回らなければ `LEFT_MOTOR_INVERT` / `RIGHT_MOTOR_INVERT` を変える。
4. **スマホ操作**: ジョイスティックで操作し、指を離す・非常停止・切断でそれぞれ止まることを確認する。
5. **電池駆動**: 床に置いて走らせ、発進時にESP32がリセットしないことを確認する。リセットする場合は「5. ノイズ・リセット対策」を見直す。

## 7. 注意事項

- **USBと電池の5Vを同時につながない。** USBで書き込むときは電源スイッチをOFFにする。シリアルモニタを見ながらモーターを回すときは、DC-DCの出力を5Vピンから外し、電池はVMにだけつなぐ。
- **リチウムイオン電池の扱い。** 保護回路付きの電池（または保護基板）を使い、充電は専用充電器で行う。ショート・過放電・変形した電池の使用を避ける。
- **GPIO2/8/9には外部回路をつながない。** 起動時の電圧レベルで起動モードが変わり、書き込みや起動に失敗することがある。
- **電池の極性を確認してから電源を入れる。** TB6612FNG・DC-DCとも逆接続で壊れる。
